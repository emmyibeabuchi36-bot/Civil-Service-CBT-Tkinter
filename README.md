# FCT Civil Service Promotion CBT Application

Tkinter + SQLite + Object-Oriented Python implementation rebuilt from the uploaded 8-branch project.

## 8 GitHub branches
1. `feature-database` — database, schema and seed data
2. `feature-auth` — registration/login and user models
3. `feature-question-bank` — question management and models
4. `feature-exam-engine` — timed exam, navigation and grading
5. `feature-results` — result storage and history
6. `feature-admin` — administrator question management
7. `feature-gui` — complete Tkinter GUI integration
8. `feature-testing-docs` — automated tests and documentation

The `main` branch is the fully merged application.

## Run
`python main.py`

Demo accounts:
- Candidate: `candidate` / `candidate123`
- Admin: `admin` / `admin123`

The database is created automatically on first run.
